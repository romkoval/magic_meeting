# Пилот 0.1: как поднять и проверить

Что получится: приложение на вашем iPhone записывает встречу, присылает текст с
пунктуацией и summary, текст можно поправить голосом и отправить. Сервер — ваша VPS
в Германии, ключ Groq лежит только на ней.

Понадобится:

- VPS с Ubuntu 22.04 или 24.04, доступ по SSH с правами sudo;
- домен или поддомен, например `mm.example.de`, с A-записью на IP сервера;
- ключ Groq (`gsk_…`) из console.groq.com;
- Mac с Xcode 26 и iPhone с iOS 17 или новее;
- для TestFlight — аккаунт Apple Developer; без него приложение ставится через Xcode
  напрямую, но бесплатная подпись живёт 7 дней.

## 1. Сервер

На VPS, один раз:

```sh
sudo apt update && sudo apt install -y caddy   # Ubuntu 24.04; на 22.04 — по caddyserver.com/docs/install
sudo ufw allow 80,443/tcp            # если включён ufw
openssl rand -hex 24                 # это будет токен приложения, сохраните его
```

Файл настроек `/etc/magic-meeting/proxy.env` (образец — `proxy/deploy/proxy.env.example`):

```sh
sudo install -d -m 755 /etc/magic-meeting
sudo nano /etc/magic-meeting/proxy.env
#   GROQ_API_KEY=gsk_...
#   CLIENT_TOKENS=<токен из openssl>
#   остальное можно оставить как в образце
sudo chmod 600 /etc/magic-meeting/proxy.env
```

В `proxy/deploy/Caddyfile` замените `proxy.example.com` на свой домен и положите файл
в `/etc/caddy/Caddyfile`, затем `sudo systemctl reload caddy`. Сертификат Let's Encrypt
Caddy получит сам.

С вашего Mac, из папки `proxy` (нужен Go 1.24, `brew install go`):

```sh
./deploy/deploy.sh user@mm.example.de
```

Скрипт соберёт сервер, поставит systemd-юнит и в конце проверит `/healthz`.

## 2. Проверка сервера и Groq

Запишите на телефон 20–30 секунд речи в Диктофоне, перенесите файл на Mac и запустите:

```sh
./deploy/smoke.sh https://mm.example.de <токен> ~/Downloads/test.m4a
```

Скрипт проверяет три вещи: сервер отвечает, Groq принимает аудио с немецкого IP
и возвращает текст, LLM делает summary. Время каждого запроса печатается.

| Что видите | Что это значит |
|---|---|
| `OK` в конце | Всё работает, можно ставить приложение |
| 401 на шаге 2 | Токен не совпадает с `CLIENT_TOKENS` |
| 503 или 502 на шаге 2 | Groq отказал или перегружен. Если повторяется — Groq не принимает запросы с этого IP, это главный риск из ТЗ §10 |
| сервер не стартует | `sudo journalctl -u magic-meeting-proxy -n 50`; чаще всего пустой или слишком короткий токен |

## 3. Приложение на iPhone

```sh
cd ios
cp Config/Local.xcconfig.example Config/Local.xcconfig
#   PROXY_HOST = mm.example.de
#   PROXY_CLIENT_TOKEN = <тот же токен>
#   DEVELOPMENT_TEAM = <Team ID из developer.apple.com или из Xcode → Settings → Accounts>
brew install xcodegen && xcodegen
open MagicMeeting.xcodeproj
```

Через Xcode: подключите iPhone, выберите его вверху и нажмите Run. На телефоне один раз
разрешите разработчика в «Настройки → Основные → VPN и управление устройством».

Через TestFlight: Product → Archive → Distribute App → TestFlight Internal Only. Сборка
появится в приложении TestFlight через 10–20 минут, ревью Apple для внутренних
тестировщиков не нужно.

## 4. Что проверяем

Отметьте, что получилось, и пришлите заметки — по ним будет план следующей итерации.

**Распознавание**
- [ ] На 3–5 настоящих встречах текст заметно лучше встроенной диктовки iOS
- [ ] Фамилии из словаря (Настройки → Словарь) распознаются правильно
- [ ] Сколько секунд ждать текст после 10 минут и после часа записи (цель — 30 секунд на час)

**Запись**
- [ ] Запись продолжается при заблокированном экране и в фоне
- [ ] Входящий звонок ставит запись на паузу, после звонка предлагается продолжить
- [ ] Дозапись приклеивает новый фрагмент в конец, summary пересобирается
- [ ] Bluetooth-гарнитура или AirPods как микрофон

**Голосовая правка**
- [ ] «Замени Курбацкий на Курбатский везде» — замены подсвечены, укладывается в 5 секунд
- [ ] «Сократи summary до трёх пунктов» — подсвечены изменённые слова
- [ ] Удержание кнопки и два нажатия работают одинаково
- [ ] «Отменить» откатывает несколько шагов подряд, в том числе после дозаписи
- [ ] Без сети показывается понятная ошибка, текст не меняется

**Отправка**
- [ ] Копирование и «Поделиться» в почту и мессенджер

Расход: Groq показывает потраченные минуты и токены в консоли — запишите их после
пилота, по ним считается себестоимость минуты и цена подписки.
